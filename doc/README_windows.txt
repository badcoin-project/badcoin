Badcoin Core
============

Intro
-----
Badcoin Core is the full-node and wallet software for the existing Badcoin
network. It validates the blockchain and communicates directly with Badcoin
peers without relying on a central server.

Setup
-----
Unpack the release files into a directory and run `badcoin-qt.exe`.

The first start may take time while Badcoin Core downloads and validates the
existing blockchain. Keep a backup of wallet data before upgrading or replacing
an older wallet installation.

Project source, issue tracking, and release information are maintained at:
  https://github.com/badcoin-project/badcoin

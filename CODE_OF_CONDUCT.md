Badcoin Community Code of Conduct

Badcoin is a community-driven, experimental multi-algorithm blockchain project.
We want the codebase, documentation, tools, and discussions around it to be open, welcoming, and respectful.

This Code of Conduct sets expectations for everyone interacting with the Badcoin project, in any space under the Badcoin name.

---

Scope

This Code of Conduct applies to:
- The Badcoin GitHub organization and all repositories
- Issue trackers, pull requests, and code reviews
- Project-related chats, forums, and social channels
- Any public space where you represent the Badcoin project or community

It applies to maintainers, contributors, users, and anyone participating in these spaces.

---

Standards

Positive behavior includes:
- Being respectful and considerate of different skill levels and backgrounds
- Offering constructive feedback rather than personal attacks
- Focusing on ideas and behavior, not individuals
- Sharing knowledge and supporting newcomers
- Admitting mistakes and learning openly

Unacceptable behavior includes:
- Harassment, insults, or threats
- Discrimination or hateful conduct
- Intimidation or sustained disruption
- Sexualized language, imagery, or unwelcome advances
- Publishing private information without permission
- Encouraging or assisting any of the above

---

Maintainer Responsibilities

Project maintainers are responsible for:
- Enforcing this Code of Conduct
- Reviewing reports of violations
- Taking consistent, fair action when inappropriate behavior occurs
- Communicating relevant decisions when appropriate

Maintainers may remove comments, code, issues, or contributions that violate this policy, and may restrict participation temporarily or permanently.

---

Reporting

Private reports can be submitted using GitHub’s built-in reporting tools:
- “Report Abuse” on a user profile
- “Report content” on issues, comments, or pull requests
- GitHub private maintainer contact options when available

GitHub forwards these reports directly to the Badcoin maintainers, keeping moderation centralized and manageable. Additional reporting channels may be added as project infrastructure expands.

---

Enforcement

Possible actions include:
1. Informal feedback
2. Written warning
3. Temporary restrictions
4. Permanent ban

Maintainers may take immediate action when necessary to maintain a safe environment.

---

Participation Notice

Contributing to the Badcoin project is a privilege.  
Maintainers reserve the right to limit or revoke participation to protect the project and its community.
